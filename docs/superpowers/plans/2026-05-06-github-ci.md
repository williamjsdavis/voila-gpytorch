# GitHub Actions CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a GitHub Actions workflow that runs lint + type-check + unit tests on every push/PR, and regression tests on pushes to `main`.

**Architecture:** A single workflow file with two jobs. `ci` runs on all branches (fast feedback); `regression` runs on push to `main` only (full inference loops are too slow for every PR). Both use `astral-sh/setup-uv` with caching so torch/gpytorch are not re-downloaded on every run.

**Tech Stack:** GitHub Actions, `astral-sh/setup-uv@v5`, `actions/checkout@v4`, Python 3.12, `uv`, `ruff`, `pyright`, `pytest`

---

### Task 1: Create the workflow file

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Create a feature branch**

```bash
git checkout -b ci/github-actions
```

- [ ] **Step 2: Create the directory**

```bash
mkdir -p .github/workflows
```

- [ ] **Step 3: Write `.github/workflows/ci.yml`**

```yaml
name: CI

on:
  push:
  pull_request:

jobs:
  ci:
    name: Lint, typecheck, unit tests
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Set up uv
        uses: astral-sh/setup-uv@v5
        with:
          enable-cache: true

      - name: Install dependencies
        run: uv sync

      - name: Lint
        run: uv run ruff check src tests scripts

      - name: Type-check
        run: uv run pyright src

      - name: Unit tests
        run: uv run pytest tests/unit -q

  regression:
    name: Regression tests
    runs-on: ubuntu-latest
    if: github.event_name == 'push' && github.ref == 'refs/heads/main'

    steps:
      - uses: actions/checkout@v4

      - name: Set up uv
        uses: astral-sh/setup-uv@v5
        with:
          enable-cache: true

      - name: Install dependencies
        run: uv sync

      - name: Regression tests
        run: uv run pytest -m regression -q
```

- [ ] **Step 4: Validate the YAML is well-formed**

```bash
python3 -c "import yaml; yaml.safe_load(open('.github/workflows/ci.yml')); print('OK')"
```

Expected output: `OK`

- [ ] **Step 5: Commit**

```bash
git add .github/workflows/ci.yml
git commit -m "Add GitHub Actions CI workflow"
```
